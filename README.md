# Alex-The-Analyst-Data-Analytics-Bootcamp

This is a practical, hands-on series that teaches the full data analytics workflow using real tools used in industry. The series focuses on moving from theory to practical job-ready skills by working with real datasets and solving realistic business problems.

Throughout the bootcamp, I learn how to:
- Use SQL to query, clean, and analyze data from databases
- Use Excel for data cleaning, formulas, pivot tables, and dashboards
- Use Python (Pandas, Matplotlib, Seaborn) for data manipulation and visualization
- Perform Data Cleaning & Data Preparation
- Do Exploratory Data Analysis (EDA) to find patterns and insights
- Create Visualizations & Dashboards to communicate insights
- Understand the end-to-end data analytics process: Raw Data → Cleaning → Analysis → Visualization → Insight
